# RTD 论文精解翻译质量指南

本指南补充 [paper-deep-dive-rst.md](paper-deep-dive-rst.md)，只管**译文质量**：
术语、句子、数字与引用怎样译得准确、通顺。页面结构、覆盖范围、公式编号、
尾部章节和覆盖自查仍以 paper-deep-dive-rst.md 为准；两者冲突时以它为准。

适用于新建或修订的论文精解页。已核验页面不因本指南发布而自动失效，
下次修订该页时再按本指南复核。

目标：**相对精确、完整**的中文全文。中文读者不看原文也能理解论文的每一步论证；
对照原文的读者能逐段找到对应。准确优先于流畅，流畅优先于文采。

## 1 翻译前：建立本篇术语表

动笔前通读全文，在私有工作记录中列出本篇术语表：

| 英文 | 中文 | 缩写 | 首次出现 |
| --- | --- | --- | --- |
| large eddy simulation | 大涡模拟 | LES | 第 1 节 |

- 优先沿用本站已有精解中的译名，保持全站一致；可先检索
  `docs/source/paper-notes/` 中的既有用法。
- 有国家标准或学科通用译名的用通用译名（如“湍流强度”“风致响应”“半潜式平台”）。
- 方法名、模型名、软件名、算例代号（如 CMRFG、SW1、HA2）保留原文，不意译。
- 首次出现写“中文（English term, 缩写）”，之后全篇只用一种写法。
- 原文对同一量用了不同名称（如正文与图题不一致）时照译，并按 paper-deep-dive-rst.md 标注差异，
  不在译文中统一。

## 2 句子：忠实且像中文

### 2.1 对应关系

- 一段对一段，一句对一句或一组可追溯的分句；不合并、不概括、不删减。
- 英文长句可以拆成两三个中文短句，但不能丢掉其中任何限定、条件或比较对象。
- 列表、条件、步骤逐项保留原顺序。

### 2.2 避免翻译腔

| 问题 | 译法示例（自拟，仅示范句式） |
| --- | --- |
| “的”字长定语 | 劣：基于所提出的改进的入口湍流生成方法的结果 → 优：采用所提出的改进入口湍流生成方法得到的结果 |
| 被动句照搬 | 劣：网格被加密到…… → 优：网格加密到……；施事者未知、需强调对象时可保留“被” |
| “进行＋动词” | 劣：对结果进行了比较 → 优：比较了结果 |
| 名词化堆叠 | 劣：实现对压力波动的有效抑制 → 优：有效抑制压力波动 |
| 代词滥用 | 英文的 it / this / which 指代不清时，译出所指名词 |
| 连接词照搬 | However / Moreover / Furthermore 不必每句都译成“然而 / 此外 / 而且”，按实际逻辑选用或省去 |

- 学术语体：用“本文”“作者”“研究表明”等原文对应的称谓；原文用 we 时可译“我们”或“本文”，
  全篇统一。不加原文没有的评价词（“显著”“重要”“创新地”）。
- 保留原文的确定程度：may / might / could → “可能”“或可”；suggest → “表明 / 提示”；
  demonstrate / prove 才译“证明”。
- 否定与比较：“not only”“less than”“up to”“approximately”逐一译出，不改变范围。

## 3 数字、单位与符号

- 数值、有效数字、单位按原文保留，不换算、不四舍五入。
- 变量与带单位的量用 `:math:`，例如 :math:`11\,\mathrm{m/s}`；不用双反引号。
- 小数点、千分位、科学计数法格式与原文一致；百分数写 :math:`15\%` 或“15%”，全篇统一。
- 公式内容逐字转写，不按教科书“纠正”；原文排印疑点按 paper-deep-dive-rst.md 保留并说明。

## 4 引用、图表与参考文献

- 文内引用保留原样式与编号：`[12]`、`Smith et al. (2020)` 等；作者名不译。
- `Fig. 3`、`Table 2`、`Eq. (5)` 在正文中译为“图 3”“表 2”“式 (5)”，全篇统一。
- 图题、表题与图注、表注逐句完整翻译，保留原编号；表头与表内文字全部译出，
  专有代号保留原文。
- 参考文献保留英文原文，不翻译作者名与题名，保留 DOI / URL。

## 5 工作方式

1. 按章节分批翻译，每批完成后立即对照原文页检查漏句、漏限定和数字。
2. 对公式密集段，先转写公式，再译前后说明文字，确认符号与正文定义一致。
3. 全篇完成后，用术语表检查译名一致性，再按 paper-deep-dive-rst.md 完成覆盖自查。
4. 最后通读一遍中文：只改不通顺的句子，不借通读删减或概括内容。

## 6 交付前自查

- [ ] 无段落合并、概括或删句；每个限定、条件、否定都已译出。
- [ ] 确定程度（可能 / 表明 / 证明）与原文一致。
- [ ] 数字、单位、符号与原文逐一对照无误。
- [ ] 文内引用、图表编号、参考文献完整对应。
- [ ] 无明显翻译腔：长“的”字链、无谓被动、“进行＋动词”、指代不清。
