# 网站主页与页面内容维护指南

本指南用于维护 WOEAI 公开网站（Sphinx / Read the Docs）的页面内容与设计。
术语以 `CONTEXT.md` 为准，事实以
[2026 网站事实来源包](../sources/2026-06-woeai-site-source-packet.md) 和已确认的公开记录为准。

## 1 网站要完成什么

网站是团队科研工作的公开证据库，按以下优先级服务读者：

1. **招生**：报考研究生、博士后的学生能看懂研究方向、近期成果和联系方式。
2. **工程应用**：潜在合作单位能看到可公开说明的应用场景和项目证据，并知道如何联系。
3. **学术可信度**：同行能核对完整论文记录、论文精解、教学与学生培养信息。

每次改动先问：这一改动让哪类读者更快找到什么？回答不了的内容不加。

## 2 页面职责

| 页面 | 职责 | 不放什么 |
| --- | --- | --- |
| `index.rst` 首页 | 一句定位、招生、研究方向入口、工程应用入口、最新学术进展、联系方式 | 长篇研究叙述、完整论文列表 |
| `EngineeringApplications.rst` 工程应用 | 按研究方向与二级方向列应用场景，再给企业项目证据和联系方式 | 合作单位名称、未公开项目细节、销售式话术 |
| `Research.rst` 科研方向 | 两个研究方向及二级方向的研究脉络、项目、图示 | 论文精解入口的重复归档 |
| `Publications.rst` 学术成果 | 按方向分组的完整期刊论文记录，挂载论文精解 | 年份小标题、Journal Papers 侧栏节点 |
| `PublicationsByYear.rst` | 按年份浏览，用 `:ref:` 回链学术成果页锚点 | 第二套锚点 |
| `Teaching.rst` 教育教学 | 课程、教改论文（教改探索）、学位论文列表 | 研究论文 |
| `About.rst` 关于本站 | 本站说明、隐私说明、版权与引用 | 机构官方口径 |
| `paper-notes/*.rst` 论文精解 | 单篇论文的完整中文精解 | 公众号导读改写稿 |

`PublicationProgress.rst` 等 `:orphan:` 页面是运营页，不进入学术导航。

## 3 首页写作

- **定位句**要具体：研究对象 + 方法 + 服务的工程问题。避免“赋能”“引领”“打造”等空话。
- **招生段**写事实：方向、近期学生第一作者成果、对申请人的期望、联系方式与建议附带的信息。
  名额、待遇、补贴、住房、落户等只写已公开确认的内容，否则以“以当年公开信息为准”表述。
- **研究方向与工程应用**每条一句话说明“研究什么问题”，链接到对应页面。
- **最新学术进展**列表由 `tools/publications/artifacts.py --write` 生成，标记之间的内容不要手改；
  标签来自公众号正文 H1 或注册表 `public_title`。公开名称统一用“论文精解”。
- **联系方式**只用 `CONTEXT.md` 列出的公开渠道，不新增电话或其他联系方式。

## 4 设计与版式

- 保持“先结论、后证据”：每个页面开头一两句说明页面用途，再展开。
- 标题中英双语格式沿用现有页面，例如 `工程应用 Engineering Applications`。
- 图片使用已公开的团队素材；视频嵌入遵守 `CONTEXT.md` 的 Embedded Video 规则，
  测试视频不得作为成果展示。
- 样式改动放在 `docs/_static/custom.css`，不在页面中写内联样式（必要的 `raw:: html`
  清除浮动除外）。
- 侧栏结构：学术成果 → 研究方向 → 二级方向 → 论文精解。不要恢复平铺的论文精解列表。

## 5 事实与公开边界

- 只发布有来源的事实。未确认的合作单位、设施、名额、补贴、新闻、奖项、指标和论文主张
  不进入公开页面；不确定事项记在 `project/` 下的计划或审校材料中，不写占位符。
- 期刊影响因子、分区、被引次数只用已确认来源，缺失时省略。
- 机构、学院、职称等信息不在本站复述，链接官方个人主页。
- 企业项目只写方向、问题类型、年份和角色；已匿名描述（如“某再生能源发电厂”）保持原样。

## 6 修改后的检查

- 运行 `./scripts/check-docs.sh`（公开安全、注册表与生成视图、单元测试、Sphinx 严格构建）。
- 发布网站版本时，按 `README.rst` 的 Site Build ID 流程运行 `./scripts/bump-site-release.py`。
- 检查首页在手机宽度下的阅读顺序：定位 → 招生 → 方向 → 工程应用 → 最新进展 → 联系方式。
