# 网站主页与页面内容维护指南

本指南用于维护 WOEAI 公开网站（Sphinx / Read the Docs）的页面内容与设计。
术语以 `CONTEXT.md` 为准，事实以
[2026 网站事实来源包](../sources/2026-06-woeai-site-source-packet.md) 和已确认的公开记录为准。

## 1 网站要完成什么

网站是团队科研工作的公开证据库，按以下优先级服务读者：

1. **招生**：报考研究生、博士后的学生能看懂研究方向、近期成果和联系方式。
2. **工程应用**：潜在合作单位能看到可公开说明的应用场景和项目证据，并知道如何联系。
3. **学术可信度**：同行能核对完整论文记录、论文精解、教学与学生培养信息。

每次改动先问：这一改动让哪类读者更快找到什么？回答不了的内容不加。

## 2 页面职责

| 页面 | 职责 | 不放什么 |
| --- | --- | --- |
| `index.rst` 首页 | WOEAI 实验室研究定位、负责人、加入团队、研究方向、工程应用、最新学术进展与联系方式 | 长篇研究叙述、完整论文列表 |
| `Recruitment.rst` 招生与申请 | 培养方向、申请类型、申请建议与联系渠道 | 未确认的当年名额、待遇和截止日期 |
| `EngineeringApplications.rst` 工程应用 | 按研究方向与二级方向列应用场景，再给企业项目证据和联系方式 | 合作单位名称、未公开项目细节、销售式话术 |
| `Research.rst` 科研方向 | 两个研究方向及二级方向的研究脉络、项目、图示 | 论文精解入口的重复归档 |
| `Publications.rst` 学术成果 | 按方向分组的完整期刊论文记录，挂载论文精解 | 年份小标题、Journal Papers 侧栏节点 |
| `PublicationsByYear.rst` | 按年份浏览，用 `:ref:` 回链学术成果页锚点 | 第二套锚点 |
| `Teaching.rst` 教育教学 | 课程、教改论文（教改探索）、学位论文列表 | 研究论文 |
| `About.rst` 关于本站 | 本站说明、隐私说明、版权与引用 | 机构官方口径 |
| `paper-notes/*.rst` 论文精解 | 单篇论文的完整中文精解 | 公众号导读改写稿 |

`PublicationProgress.rst` 等 `:orphan:` 页面是运营页，不进入学术导航。

## 3 首页写作

- **主体**为 WOEAI 实验室研究团队；使用 `CONTEXT.md` 已确认的中英文实验室品牌，首屏明确其为研究团队，不暗示建制单位、设施或正式成立。李朝以负责人呈现，保留已确认的学术身份和官方主页；不推定成员或规模。成果按作者与原论文保留归属，论文精解与 Highlights 是学术解读。
- **定位句**要具体：研究对象 + 方法 + 服务的工程问题。避免“赋能”“引领”“打造”等空话。
- **招生段**写事实：方向、近期学生第一作者成果、对申请人的期望、联系方式与建议附带的信息。
  名额、待遇、补贴、住房、落户等只写已公开确认的内容，否则以“以当年公开信息为准”表述。
- **研究方向与工程应用**每条一句话说明“研究什么问题”，链接到对应页面；两大方向各补一句有论文支持的具体方法与工程价值，图神经网络和 Kriging 代理模型按真实方法名称呈现，不把所有方向泛称为 AI 成果。
- **近期学术进展**放在原成果卡片位置，只保留这一段；中英文共用 `woeai/publications/homepage.py`。先筛资格，再按研究方向分组，按论文发表日期倒序各取最多三篇，沿用三列卡片；不足三篇就少展示，绝不用未制作论文补位。资格须同时满足：列入公开明确选择名单 `docs/data/home-progress-selection.json`、`custom.content_production = included`、对应公开公众号正文存在且非空、当前内容审校有效。内容审校按[注册表指南](publication-registry.md#首页内容资格)判定，计划制作或单纯上传过草稿均不能替代。无需正式群发 URL、私有草稿 ID 或真实手机预览。
- 选择名单是独立的首页编辑选择，不宣称作者主导或成果归属，也不按作者顺序推断。2026-10-18 首次兼容范围固定迁移自当日明确纳入制作的44篇，不改写其渠道状态；当前制作和审校资格仍须逐篇通过。未来新增记录、外部论文解读均默认不入名单，须维护者明确选择，不自动继承制作资格。`docs/data/home-progress.json` 仅维护展示文案，不能代替选择名单。
- CSL 只有年份时使用同年公开书目日期，同日沿用论文库顺序；不把网站更新或导读制作日期当作论文日期。完整公开论文仍保留在学术成果归档。缺少已批准配图或 RTD 精解时只保留真实题录和实际可用入口，不造摘要、图片或占位链接。
- 卡片直接显示完整引用，保留原论文题目和完整作者，不折叠、不保留“原论文题目与作者”提示行。已存在的英文 highlight 或中文精解按实际文件提供入口，并明确标记中文。仅复用已批准封面；中文卡片由 `tools/publications/artifacts.py --write` 生成，标记之间的内容不要手改。保留 `selected-work` 和 `latest-progress` 既有锚点，二者指向同一栏目。
- **联系方式**只用 `CONTEXT.md` 列出的公开渠道，不新增电话或其他联系方式。
- **交流与合作**保留首页 `join-contact` 锚点，分别以“加入团队”进入既有招生详情页、“工程合作”进入工程应用页的既有交流说明；全站同名导航指向这个首页栏目，招生详情页继续保留原用途。

## 4 设计与版式

- 保持“先结论、后证据”：每个页面开头一两句说明页面用途，再展开。
- 标题中英双语格式沿用现有页面，例如 `工程应用 Engineering Applications`。
- 图片使用已公开的团队素材；视频嵌入遵守 `CONTEXT.md` 的 Embedded Video 规则，
  测试视频不得作为成果展示。
- 首页 `home.html` 与 RTD 的 `layout.html` 扩展共用 `brand-header.html` 和 `brand-links.html`；所有页面的主导航目标一致，论文页归属学术成果。共用色彩和系统字体；首页展示规则以 `.woeai-home-page` 为作用域，阅读外壳规则以 `.wy-body-for-nav` 为作用域。内页保留嵌套侧栏、搜索、面包屑、公式与受控正文宽度，不把正文改成展示卡片。窄屏网站导航使用原生 details，阅读目录沿用 RTD 的抽屉并同步键盘焦点与展开状态。样式改动放在 `docs/_static/custom.css`，不在页面中写内联样式（必要的 `raw:: html`
  清除浮动除外）。
- 侧栏结构：学术成果 → 研究方向 → 二级方向 → 论文精解。不要恢复平铺的论文精解列表。

## 5 事实与公开边界

- 只发布有来源的事实。未确认的合作单位、设施、名额、补贴、新闻、奖项、指标和论文主张
  不进入公开页面；不确定事项记在 `project/` 下的计划或审校材料中，不写占位符。
- 期刊影响因子、分区、被引次数只用已确认来源，缺失时省略。
- 机构、学院、地址和行政职务不在本站复述，链接官方个人主页。用户已明确确认以实验室研究团队负责人身份展示“李朝”和学术职称“教授 · 博士生导师”；不放个人照片。
- 企业项目只写方向、问题类型、年份和角色；已匿名描述（如“某再生能源发电厂”）保持原样。

## 6 修改后的检查

- 运行 `./scripts/check-docs.sh`（公开安全、注册表与生成视图、单元测试、Sphinx 严格构建）。
- 发布网站版本时，按 `README.rst` 的 Site Build ID 流程运行 `./scripts/bump-site-release.py`。
- 检查首页在窄屏下的阅读顺序：实验室研究团队定位与负责人（含加入团队入口）→ 两条主线 → 近期学术进展 → 应用场景 → 招生与联系。浏览器窄屏检查不等于真实手机微信验收。

## 7 英文入口

- `en/index`、`en/Research`、`en/Publications`、`en/JoinUs` 和 `en/Search` 共用中文站的视觉外壳、公开联系方式和论文注册表。英文分类名称只在 `woeai/publications/taxonomy.py` 维护显示映射，不产生第三研究主方向。
- `en/highlights/` 是每篇约 150–250 词的原创英文研究概述，说明问题、贡献、工程意义和边界，不是 44 篇中文精解的回译。来源处明确标记 Chinese reading notes，并给出原论文 DOI。未经确认授权的论文原图不进入英文版；原创概念示意需标明不属于研究数据。
- `english_site.py` 在构建时从同一注册表投影公开书目信息。不得把工作流证据或私有源文件定位传入页面上下文。
- 只有真实对应的页面提供页级语言切换；无对应页的入口明确标记 EN home / 中文首页。搜索使用共享索引并说明结果可能包含两种语言。
- Join Us 欢迎国际硕士和博士申请人，保留 Official Admissions、Application Portal 及官方个人主页入口。申请条件与资助以官方信息为准，不写未经确认的申请时间、名额、录取或资助承诺。

- 英文 Join Us 区分 Academic contact 与 Official application；背景、CV与研究问题仅为初次学术联系建议，不是学校官方录取条件。
- 中英文研究方向卡以文字、标签、方法和证据链接为主，按已批准设计移除两张方向概念图；首屏既有概念图保留其准确替代文本及生成图注，不冒充研究数据。近期进展继续使用解读封面，每篇唯一源由当前审稿记录 `cover_image` 指向 `wechat/assets/public-safe/<ref>/cover.png`；Sphinx仅在构建输出生成六篇首页副本，与唯一源字节一致，不在源码静态目录手工维护另一套，保留900×383完整比例及“AI生成、非研究数据”图注；不以固定高度裁切文字。封面、正文科研图与方向示意图是不同用途，改用正文代表图须明确选择，不因文件名不同就判断版本过期。
