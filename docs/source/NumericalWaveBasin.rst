数值水池 Numerical Wave Basin
==================================================

:doc:`海洋能源结构 <MarineEnergyStructures>` · :doc:`研究方向总览 <Research>`

波浪的生成、传播和吸收，以及自由面与结构之间的相互作用，决定水动力计算的可信程度。数值水池关注这些过程本身的建模与验证，而不只是把水动力载荷输入整机模型。研究重点在于明确误差来源，建立逐步可核对的验证路径。

- 怎样在有限计算域中生成目标波浪，并控制边界反射和传播误差？
- 自由面、水流与结构相互作用怎样得到网格和时间步可靠性检验？
- 与解析解、基准算例或物理试验的对照，能否区分造波误差与结构响应误差？

.. _numerical-wave-basin-methods:

方法与创新
----------------------------------------

数值造波、传播吸收与自由面建模为相互作用分析提供支撑。方法是否可信，取决于边界、网格与基准验证。

验证应先检查造波与传播，再进入结构相互作用和耦合算例；每一步分别交代条件和误差来源。

仍待解决的问题
----------------------------------------

造波条件、边界处理与收敛检验需要形成可复核的验证证据。当前公开材料尚不足以给出本方向独立的定量结论，不能据此宣称方法突破或全工况验证。
